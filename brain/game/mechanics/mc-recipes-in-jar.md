# Recipes and tags live in the inner jar

## Facts
- The downloadable `server.jar` is a bundler. The real server is `META-INF/versions/26.1.2/server-26.1.2.jar` inside it, and its `data/minecraft/` tree holds the datapack: `recipe/<id>.json` (1516 entries in 26.1.2, of every recipe type) and `tags/item/<tag>.json`.
- `--reports` (the data generator) writes `blocks.json`, `packets.json`, `registries.json`, `commands.json` and item component reports, but no recipes and no tags.
- A recipe JSON has `type` (`minecraft:crafting_shaped`, `minecraft:crafting_shapeless`, smelting, smithing, stonecutting, `crafting_special_*` ...), `result {id, count}` (count defaults to 1), and either `pattern` + `key` or `ingredients`. An ingredient is an item id, a `#tag`, or a list of those.
- A tag JSON is `{"values": [...]}` whose entries are item ids, `#tags` (nested) or `{"id": ...}` objects.
- 1030 of the recipes are shaped or shapeless crafting; that is the size of our table.

## Gotchas
- The same `dimension_type`, worldgen and loot data live in the same inner jar; read them with `unzip -p server.jar META-INF/versions/26.1.2/server-26.1.2.jar > inner.jar` then `unzip -p inner.jar data/minecraft/...`.

## Limits
The recipe-type list and the 1516 count were read from the jar listing on 2026-10-09; the jar is not a repo file, so only the claims about what datagen extracts are anchored.
