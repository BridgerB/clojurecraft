# Snake-case gamerules

## Facts
- 26.1.2 names gamerules in snake_case: `gamerule keep_inventory true`. The pre-26 camelCase `keepInventory` is rejected (ruststeve's race script says so and re-applies the rule on every race; steve's main applies `keep_inventory` over RCON).
- Our `data/reports/reports/commands.json` (generated by `scripts/datagen.sh`, gitignored) lists `keep_inventory` and no `keepInventory` (read 2026-10-09).
- Gamerules are per world: a world reset loses them, so a harness must set them after every fresh world.

## Gotchas
- An RCON `gamerule keepInventory true` returns an error string, not an exception; a fixture that ignores replies sets nothing.
- clojurecraft sets no gamerules yet; death and respawn are issue #5, where `keep_inventory` decides whether the grid and kit survive.
