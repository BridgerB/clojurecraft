Snapshots are no longer kept in git. A snapshot is a moment the sim race kept from before the choice that failed (`simrace/chosen-moment`), with everything the next tick depends on, and the window it is judged over (`:snapshot/moment`). `bb issue-check fetch <n>` brings an issue's into `cache/issues/<n>/` (never committed), and `clojure -M:simrace --judge` plays them, seconds a snapshot, never a run from the landing; judge them with `bb probe`.

The 99 directories that lived here are the release asset `snapshots-2026-11-07.tar` of the release `snapshots-2026-11-07` (`INDEX.edn` lists them by issue); extract one into `cache/issues/` to judge an old issue. A pull request that adds snapshots here is still judged by `issue.yml`, each under GitHub's 100 MiB file limit and two an issue at most (`issues_test`).
