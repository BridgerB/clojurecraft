Each `test/issues/<n>/` holds the snapshots a fix for issue #n is judged by: two at most, from two different worlds, never two seeds of the same world and moment (`an-issue-keeps-two-snapshots-at-most`), each under GitHub's 100 MiB file limit (`every-snapshot-fits-on-github`). Bring them in with `bb issue-check fetch <n>`.

A snapshot is a moment the sim race kept from before the choice that failed (`simrace/chosen-moment`), with everything the next tick depends on, and the window it is judged over (`:snapshot/moment`). The pull request's check judges only the issues the PR names, on the base code (each moment must reproduce its failure) and on the PR's code (none may), with `clojure -M:simrace --judge`: seconds a snapshot, never a run from the landing.
